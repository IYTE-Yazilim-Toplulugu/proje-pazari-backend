# Dashboard Screenshots

Place Grafana dashboard screenshots here after running the stack.

| File | Dashboard |
|---|---|
| `app-performance-dashboard.png` | Application Performance — JVM, CPU, HTTP metrics |
| `business-metrics-dashboard.png` | Business Metrics — users, projects, submissions |
| `infrastructure-dashboard.png` | Infrastructure — PostgreSQL, Redis, MinIO, Elasticsearch |

## How to capture

1. Start the full stack: `docker-compose up -d`
2. Open each dashboard in Grafana (http://localhost:3030)
3. Click **Share (chain icon) → Export → Copy link** or use the camera icon for a PNG render
4. Save the file with the name listed above
